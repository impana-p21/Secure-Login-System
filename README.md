# Secure Login System

## Description
A secure login system built using Flask that supports user registration, login, password hashing with bcrypt, session management, SQL injection protection, and optional two-factor authentication.

## Features
- User Registration
- User Login
- bcrypt Password Hashing
- SQLite Database
- Input Validation
- SQL Injection Protection
- Session Management
- Logout
- Optional OTP-based 2FA

## Technologies
- Python
- Flask
- SQLite
- bcrypt
- HTML
- CSS

## Future Enhancements
- Email OTP
- Google Authenticator

- Remember Me
